# Our Story V7 Fix — GitHub Pages Ready

Versi ini berasal dari source `our story v7 fix.zip` dan mempertahankan revisi pengguna. Project sudah dibersihkan dari `node_modules`, `.next`, `.vinext`, `.wrangler`, dan artifact lokal lain yang tidak perlu dipush.

## Local preview

```powershell
npm install
npm run dev
```

Atau double-click `RUN-WINDOWS.bat`.

## Deploy

Baca `DEPLOY-GITHUB-PAGES.md` atau gunakan `PUSH-TO-GITHUB.bat` setelah membuat repository kosong di GitHub.

## Privacy note

Site menyertakan `robots.txt` + `noindex` untuk mengurangi kemungkinan muncul di search engine. Ini bukan password/access control.
